Codex

Skyline Flap — dusk arcade art

  • 905 lines
  • canvas never paints
  • Diverges hardest on art: a dusk arcade treatment rather than the original's daytime palette, with redrawn bird and pipe set.
  • Renders through a DOM fallback scene — sun, clouds, skyline, pipes and bird in CSS — and as shipped that fallback is the live renderer even in a full browser.
  • Cause: the game column and the canvas both carry id="game", so getElementById('game') returns the section, ctx is null, and the 2D canvas samples as a single flat colour. Playable, but on the degraded path.

About the bake-off

All three implement the same spec (kept in the root README.md): a fixed logical canvas CSS-scaled to the window, a fixed 60Hz simulation with an accumulator, no image, font or audio assets, best score in localStorage, and a debug hook for automated testing. Only the art direction and the tuning were left to each agent.

Each entry is a self-contained folder — claude/, codex/, hermes/ — with its own index.html, so they also run straight off file:// with no server.
